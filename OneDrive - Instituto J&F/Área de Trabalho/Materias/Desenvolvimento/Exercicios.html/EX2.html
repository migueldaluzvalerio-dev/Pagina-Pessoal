Função quadratica

Criada a parir de graficos e pontos, que geram uma parábola.


Formula:

F(x) = ax2 + bx + c

Componentes:

a- Coeficiente Principal (ou Quadrático), define concavidade. Se (a > 0) é voltada pra cima, se (a < 0) para baixo.

b- "Coeficiente linear", que acompanha o termo de primeiro grau, onde a parabola cruza com o eixo y;

c- Termo independente, não acompanha variável. Graficamente respresentando o ponto exato onde a parábola corta o eixo y (ordenada), (0,c).

Exemplo:

Função completa = f(x) = 6x2 -4x +5

a = 6
b = -4
c = 5
